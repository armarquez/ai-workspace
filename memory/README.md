# memory

Shared notes written by `basic-memory` (see `mcp/servers.toml`), read by
every provider through the same MCP server. Plain Markdown — reviewable,
diffable, and committed like any other file in this repo.

`just doctor` registers this directory as the `ai-workspace` basic-memory
project (`basic-memory project add ai-workspace <path>`) so every CLI
resolves to the same store without per-CLI configuration.
